🤖 Antigravity + Typebot

Guía para conectar Antigravity (Groq + IA) con Typebot y crear una charla amena con tus usuarios.

Nuevos endpoints Typebot
V6 flow importable

📡 Endpoints disponibles

El servidor ahora expone estos endpoints específicos para Typebot:

POST /api/typebot

Webhook principal. Recibe sessionId + message, devuelve la respuesta de IA.

POST /api/typebot/registrar

Registra leads. Recibe sessionId, nombre, email, etc.

POST /api/typebot/reset

Reinicia una sesión.

GET /api/typebot-flow

Descarga el flow JSON para importar en Typebot.

📥 Importar el Flow en Typebot

1
Abre Typebot Studio

Crea un nuevo Typebot y selecciona "Importar un archivo" (Import a file).

Selecciona el archivo typebot-flow.json que está en la raíz del proyecto.

2
Configura la URL del webhook

En los bloques "Webhook" (HTTP Request), actualiza la URL si tu servidor corre en otro puerto o dominio:

http://localhost:3000/api/typebot

En producción, cámbiala a tu dominio real.

3
Prueba el flujo

Usa el botón "Test" en Typebot para probar la conversación. Escribe un mensaje y el asistente Antigravity responderá.

🔌 Cómo configurar manualmente (si no usas el JSON)

1 Bloque: HTTP Request

Arrastra un bloque HTTP Request (categoría Integraciones) al canvas.

Configuración:

URL: http://localhost:3000/api/typebot
Método: POST
Headers:
  Content-Type: application/json

Body (JSON):
{
  "sessionId": "{{sessionId}}",
  "message": "{{userMessage}}"
}

Mapeo de respuesta:

respuesta → variable "aiResponse"
status    → variable "apiStatus"
2 Bloque: Condition

Después del HTTP Request, añade un bloque Condition para bifurcar:

Si "apiStatus" es igual a "SUCCESS" → mostrar respuesta
Si "apiStatus" es igual a "BLOQUEO_REGISTRO" → ir a registro
3 Bloque: Text Bubble

Muestra la respuesta de la IA usando la variable:

{{aiResponse}}

Typebot renderizará automáticamente Markdown, imágenes, audios, etc.

🧠 Variables en Typebot

El flow usa estas variables. Se crean automáticamente al importar el JSON:

  • userMessage — Mensaje que escribe el usuario
  • apiStatus — Estado de la respuesta (SUCCESS / BLOQUEO_REGISTRO)
  • aiResponse — Texto de respuesta de Antigravity
  • hasInteracted — Control para saber si ya ha conversado
  • sessionIdVar — ID de sesión para el backend
  • regNombre, regEmail, regTelefono, regEmpresa — Datos del formulario

⚙️ Personalización

🎨 El Prompt del Asistente

Edita agente.md para cambiar la personalidad y tono de Antigravity. Este archivo se inyecta automáticamente como system prompt en cada llamada a Groq.

📚 Base de Conocimiento

Edita biblioteca.txt para agregar información que Antigravity debe conocer (precios, servicios, horarios, etc.).

🔄 Límite de interacciones

Por defecto, Antigravity permite 2 mensajes gratis antes de pedir registro. Puedes cambiar este número en:

src/server.ts → línea: session.interacciones >= 2

🚀 Producción

Para usar en producción:

  1. Cambia todas las URLs de http://localhost:3000 a tu dominio real
  2. Asegúrate de que GROQ_API_KEY esté configurada en .env
  3. Ejecuta npm start para iniciar el servidor
  4. En Typebot, cambia las URLs de los bloques Webhook y vuelve a probar
